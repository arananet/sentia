## Purpose

The /take-apart page works: its model, tour, gauges and production serving shape are proven by wo-gh-9 and wo-gh-11. What fails is the product itself. Each layer is one rounded box primitive with a flat color, and the product owner judged the result on 2026-10-31: the layers read as generic blocks, not as the Sentia Patch One. This order replaces only the geometry. A deterministic Blender build models the Patch One from the repo's own reference anchors and exports it as one glTF binary; the page loads that binary and binds its named layer nodes to the existing state function. The governing specs for the page and its serving stay .openspec/specs/take-apart/spec.md and .openspec/specs/take-apart-bundling/spec.md; this spec governs the model asset, its integration and the fidelity gate. The builder and reviewer-design run on GPT-6 Astra; the spec writer, test writer and the other reviewers run on claude-sonnet-5-5, per ANVIL policy.

## References (the fidelity anchor)

- design/reference/product-reference.png: the identity anchor. The canonical Patch One: a flat, thin, matte off white square patch with strongly rounded corners, the SENTIA wordmark in dark print, and a teal cyan LED line.
- design/reference/quality-board-1.png and design/reference/quality-board-2.png: the quality anchor. Photorealistic studio boards whose exploded views show the layer materials: matte silicone top cover, porous comfort foam, a detailed PCB with real components, translucent adhesive and release liner films.
- src/facts.js FACTS.layers: the five layer names, in stack order, and their product descriptions. The facts file is not edited by this order.

## Requirements

### The build

- R1 (deterministic Blender build): A build script at blender/build_patch_one.py, driven by the deterministic entry blender/build_all.py, models the product and exports the asset and the beauty renders. It runs under headless Blender pinned to the 4.5 LTS series (4.5.15, the version the workflow installs and smoke gates before the line). The workflow runs blender/build_all.py again after the line, before the suite, so the committed asset and renders always come from the committed script, never from a station's ad hoc invocation. The script is the only producer of the asset: no hand edited GLB, no downloaded model, no external texture or image file. Any texture the materials need is generated inside the script.
- R2 (units and proportions): The script works in millimetres with the scene unit system set so one exported glTF unit equals one millimetre, and the client treats loaded units as millimetres. The footprint is the model's FOOTPRINT_MM 36 square with CORNER_RADIUS_MM 9. Layer thicknesses are the model's: Top cover 0.6, Comfort foam 0.7, Sensing and processing board 0.5, Adhesive layer 0.4, Release liner 0.3, summing to the 2.5 mm profile. The product is modeled true scale: no vertical exaggeration inside the asset. The page's study exaggeration stays where it lives today, in the client, applied per layer node about its own centre exactly as the current geometry construction applies it.

### The asset

- R3 (one GLB, five named nodes): The build exports one glTF binary (GLB). Its scene has exactly five top level nodes, in this order, named exactly as the page's model names the layers: Top cover, Comfort foam, Sensing and processing board, Adhesive layer, Release liner. Each top level node is the parent of that layer's meshes and nothing else; there are no other top level nodes. Each node's origin sits at that layer's assembled centre, so its exported translation is (0, centre, 0) with the centre equal to src/take-apart-model.js layerCenterMm for that layer at t=0, within 0.01. All geometry is local to its node.
- R4 (the asset in the repo): The GLB is carried in the repo following this codebase's binary pattern: a base64 constant module at src/patch-one-glb.js, exported bytes byte identical to the build's export. A new route /models/patch-one.glb in src/index.js serves the decoded bytes as model/gltf-binary. The GLB measures at or under 800 KB; the enforcing test states the measured size either way, and the run report states it too. If the measured size exceeds the budget, the build's geometry and texture discipline is tightened until it fits; the budget is not raised by this order.
- R5 (cover detail): The top cover carries the product's real silhouette and detail: a softly rounded, low profile shell whose top face is gently crowned, never a box with rounded corners; the SENTIA wordmark as modeled or textured detail on the top face, in the dark ink of the reference, oriented to read as it reads in product-reference.png; and the teal LED line as a thin strip on the top face, in the brand teal, positioned as in the reference. The earlier take apart spec's no text clause governed the primitive study model and is superseded for the cover by this requirement; no other layer gains text.
- R6 (layer materials and parts): The foam reads as a thin porous layer (fine surface texture generated in the build, pale warm gray, high roughness). The board is a real board: an ink green substrate carrying component geometry, at minimum a main chip, at least two sensor discs, a battery and fine traces or their textured equivalent, all inside the layer's thickness envelope. The adhesive layer is a thin translucent film. The release liner is the lightest thin film, modeled slightly peeled or offset as in the reference exploded views (a lifted corner or an offset tab), still a child of its node and still stacking flush at rest apart from the modeled peel. """Patch One in mm. Blender 4.5.15; no external models, fonts or textures.
The glTF numbers intentionally remain millimetres (exporter does not rescale).

ROOT = Path(__file__).resolve().parents[1]

def material(name, rgb, roughness=.7, metallic=0, alpha=1):
    m = bpy.data.materials.new(name)
    m.use_nodes = True
    p = m.node_tree.nodes.get('Principled BSDF')
    p.inputs['Base Color'].default_value = (*rgb, alpha)
    p.inputs['Roughness'].default_value = roughness
    p.inputs['Metallic'].default_value = metallic
    if alpha < 1:
        p.inputs['Alpha'].default_value = alpha
        m.surface_render_method = 'DITHERED'
    return m


def attach(obj, name, parent, mat):
    obj.name = name
    obj.parent = parent
    obj.data.materials.append(mat)
    return obj


def outline(a=18, r=9, count=16):
    points = []
    for cx, cy, start in [(a-r,a-r,0),(-a+r,a-r,90),(-a+r,-a+r,180),(a-r,-a+r,270)]:
        for i in range(count):
            angle = math.radians(start+i*90/(count-1))
            points.append((cx+r*math.cos(angle),cy+r*math.sin(angle)))
    return points


def shell(name, parent, mat, rings, peel=False):
    pts = outline()
    verts = []
    for scale, z in rings:
        for x,y in pts:
            lift = .12 * max(0, (x-y-21)/9)**2 if peel else 0
            verts.append((x*scale,y*scale,z+lift))
    n = len(pts)
    faces = [tuple(reversed(range(n)))]
    for j in range(len(rings)-1):
        for i in range(n):
            k=(i+1)%n
            faces.append((j*n+i,j*n+k,(j+1)*n+k,(j+1)*n+i))
    faces.append(tuple(range((len(rings)-1)*n,len(rings)*n)))
    mesh=bpy.data.meshes.new(name)
    mesh.from_pydata(verts,[],faces); mesh.update()
    obj=bpy.data.objects.new(name,mesh); bpy.context.collection.objects.link(obj)
    attach(obj,name,parent,mat)
    for p in mesh.polygons: p.use_smooth = len(p.vertices)==4
    uv=mesh.uv_layers.new(name='UVMap')
    for poly in mesh.polygons:
        for index in poly.loop_indices:
            co=mesh.vertices[mesh.loops[index].vertex_index].co
            if len(poly.vertices)==4:
                uv.data[index].uv=((co.x+co.y+36)/36,co.z/9)
            else:
                uv.data[index].uv=((co.x+18)/36,(co.y+18)/36)
    return obj


def box(name,parent,mat,xyz,size,bevel=.025):
    bpy.ops.mesh.primitive_cube_add(size=1,location=xyz)
    o=bpy.context.object; o.dimensions=size
    bpy.ops.object.transform_apply(location=False,rotation=False,scale=True)
    if bevel:
        mod=o.modifiers.new('Machined edges','BEVEL');mod.width=bevel;mod.segments=2
        bpy.ops.object.modifier_apply(modifier=mod.name)
        mod=o.modifiers.new('Weighted normals','WEIGHTED_NORMAL')
        bpy.ops.object.modifier_apply(modifier=mod.name)
    # Bevel interpolates unused cube UVs with tiny run-dependent rounding.
    # These untextured parts need no UVs; remove them for byte-identical exports.
    for uv in list(o.data.uv_layers):o.data.uv_layers.remove(uv)
    return attach(o,name,parent,mat)


def disc(name,parent,mat,x,y,r,z,h):
    bpy.ops.mesh.primitive_cylinder_add(vertices=48,radius=r,depth=h,location=(x,y,z))
    o=bpy.context.object
    for p in o.data.polygons: p.use_smooth=len(p.vertices)==4
    return attach(o,name,parent,mat)


def foam_texture(mat):
    # Seeded cell pits, generated in-process and embedded in GLB. A repeating
    # microcell tile provides real surface detail in both renderers.
    rng=random.Random(12)
    size=256
    values=[.88]* (size*size)
    for _ in range(1800):
        x,y=rng.randrange(size),rng.randrange(size);r=rng.choice([1,1,2,3])
        for dy in range(-r,r+1):
            for dx in range(-r,r+1):
                d=(dx*dx+dy*dy)/(r*r)
                if d<=1:
                    idx=((y+dy)%size)*size+(x+dx)%size
                    values[idx]=min(values[idx], .67+.21*d)
    img=bpy.data.images.new('Generated foam microcells',width=size,height=size)
    pixels=[]
    for v in values: pixels.extend((v,v*.98,v*.93,1))
    img.pixels=pixels;img.pack()
    nt=mat.node_tree;p=nt.nodes.get('Principled BSDF')
    tex=nt.nodes.new('ShaderNodeTexImage');tex.image=img
    uv=nt.nodes.new('ShaderNodeTexCoord');mapping=nt.nodes.new('ShaderNodeMapping');mapping.inputs['Scale'].default_value=(4,4,1)
    nt.links.new(uv.outputs['UV'],mapping.inputs['Vector']);nt.links.new(mapping.outputs[0],tex.inputs['Vector'])
    nt.links.new(tex.outputs['Color'],p.inputs['Base Color'])
    normal_image=bpy.data.images.new('Generated foam pore normals',width=size,height=size)
    normal_image.colorspace_settings.name='Non-Color'
    normals=[]
    for y in range(size):
        for x in range(size):
            dx=values[y*size+(x+1)%size]-values[y*size+(x-1)%size]
            dy=values[((y+1)%size)*size+x]-values[((y-1)%size)*size+x]
            v=Vector((-dx,-dy,1)).normalized()
            normals.extend((v.x*.5+.5,v.y*.5+.5,v.z*.5+.5,1))
    normal_image.pixels=normals;normal_image.pack()
    normal_tex=nt.nodes.new('ShaderNodeTexImage');normal_tex.image=normal_image
    nt.links.new(mapping.outputs[0],normal_tex.inputs['Vector'])
    normal=nt.nodes.new('ShaderNodeNormalMap');normal.inputs['Strength'].default_value=.45
    nt.links.new(normal_tex.outputs['Color'],normal.inputs['Color']);nt.links.new(normal.outputs[0],p.inputs['Normal'])

function nodeMatrix(n) {
  if (n.matrix) return n.matrix;
  const [x, y, z, w] = n.rotation || [0, 0, 0, 1], [sx, sy, sz] = n.scale || [1, 1, 1], [tx, ty, tz] = n.translation || [0, 0, 0];
  return [
    (1 - 2 * (y * y + z * z)) * sx, 2 * (x * y + z * w) * sx, 2 * (x * z - y * w) * sx, 0,
    2 * (x * y - z * w) * sy, (1 - 2 * (x * x + z * z)) * sy, 2 * (y * z + x * w) * sy, 0,
    2 * (x * z + y * w) * sz, 2 * (y * z - x * w) * sz, (1 - 2 * (x * x + y * y)) * sz, 0,

// Bounds of a subtree via POSITION accessor min/max corners. `from` is the
// matrix applied above the subtree root (IDENT for world, inverse-free local
// is handled by passing the root node's own matrix as IDENT start and skipping it).
function bounds(gltf, idx, parent, skipRoot) {
  const n = gltf.nodes[idx];
  const m = skipRoot ? parent : mul(parent, nodeMatrix(n));
  const lo = [Infinity, Infinity, Infinity], hi = [-Infinity, -Infinity, -Infinity];
  const add = (p) => { for (let i = 0; i < 3; i++) { lo[i] = Math.min(lo[i], p[i]); hi[i] = Math.max(hi[i], p[i]); } };
  if (n.mesh != null) {
    for (const prim of gltf.meshes[n.mesh].primitives) {
      const acc = gltf.accessors[prim.attributes.POSITION];
      assert.ok(acc.min && acc.max, 'POSITION accessor carries min and max');
      for (let c = 0; c < 8; c++) {
        const p = [c & 1 ? acc.max[0] : acc.min[0], c & 2 ? acc.max[1] : acc.min[1], c & 4 ? acc.max[2] : acc.min[2]];
        add([0, 1, 2].map((r) => m[r] * p[0] + m[4 + r] * p[1] + m[8 + r] * p[2] + m[12 + r]));
      }
    }
  }
  for (const c of n.children || []) {
    const b = bounds(gltf, c, m, false);
    if (b) { add(b.lo); add(b.hi); }
  }
  return lo[0] === Infinity ? null : { lo, hi };
}

// ---------------------------------------------------------------- PNG pixels
function decodePng(buf) {
  assert.ok(buf.subarray(0, 8).equals(Buffer.from([0x89, 0x50, 0x4e, 0x47, 0x0d, 0x0a, 0x1a, 0x0a])), 'not a PNG');
  let off = 8, w, h, bpp, idat = [];
  while (off < buf.length) {
    const len = buf.readUInt32BE(off), type = buf.toString('ascii', off + 4, off + 8);
    const data = buf.subarray(off + 8, off + 8 + len);
    if (type === 'IHDR') {
      w = data.readUInt32BE(0); h = data.readUInt32BE(4);
      assert.equal(data[8], 8, '8 bit PNG expected'); assert.equal(data[12], 0, 'non interlaced PNG expected');
      bpp = { 2: 3, 6: 4 }[data[9]]; assert.ok(bpp, 'RGB or RGBA PNG expected');
    } else if (type === 'IDAT') idat.push(data);
    else if (type === 'IEND') break;
    off += 12 + len;
  }
  const raw = zlib.inflateSync(Buffer.concat(idat)), stride = w * bpp, px = Buffer.alloc(h * stride);
  for (let y = 0; y < h; y++) {
    const f = raw[y * (stride + 1)], row = raw.subarray(y * (stride + 1) + 1, (y + 1) * (stride + 1));
    for (let x = 0; x < stride; x++) {
      const a = x >= bpp ? px[y * stride + x - bpp] : 0, b = y ? px[(y - 1) * stride + x] : 0, c = x >= bpp && y ? px[(y - 1) * stride + x - bpp] : 0;
      const p = a + b - c, pa = Math.abs(p - a), pb = Math.abs(p - b), pc = Math.abs(p - c);
      const pred = [0, a, b, (a + b) >> 1, pa <= pb && pa <= pc ? a : pb <= pc ? b : c][f];
      px[y * stride + x] = (row[x] + pred) & 255;
    }
  }
  return { w, h, bpp, px };
}

    assert.ok(w >= 800 && h >= 800, `${name} is ${w}x${h}`);
    const at = (x, y) => [0, 1, 2].map((c) => px[(y * w + x) * bpp + c]);
    for (const [x, y] of [[2, 2], [w - 3, 2], [2, h - 3], [w - 3, h - 3]]) {
      at(x, y).forEach((v, c) => assert.ok(Math.abs(v - [0xfa, 0xfa, 0xf6][c]) <= 4, `${name} corner (${x},${y}) channel ${c} is ${v}, brand paper is ${[0xfa, 0xfa, 0xf6][c]}`));
    }
    // The product occupies the middle: many tones, a real luminance span, not one flat field.
    const tones = new Set();
    let min = 255, max = 0, nonPaper = 0, total = 0;
    for (let y = 0; y < h; y += 3) for (let x = 0; x < w; x += 3) {
      const [r, g, b] = at(x, y);
      total++;
      if (Math.abs(r - 250) > 6 || Math.abs(g - 250) > 6 || Math.abs(b - 246) > 6) nonPaper++;
      if (x > w * 0.25 && x < w * 0.75 && y > h * 0.25 && y < h * 0.75) {
        tones.add(`${r >> 3},${g >> 3},${b >> 3}`);
        const l = (r + g + b) / 3; min = Math.min(min, l); max = Math.max(max, l);
      }
    }
    assert.ok(tones.size >= 60 && max - min >= 60, `${name}: ${tones.size} tones, span ${max - min} in the central half`);
    assert.ok(nonPaper / total >= 0.04, `${name}: product covers ${(100 * nonPaper / total).toFixed(1)}% of the frame, the product must be large`);
    assert.ok(nonPaper / total <= 0.8, `${name}: product covers ${(100 * nonPaper / total).toFixed(1)}% of the frame, no studio filler`);
  });
}

const ROUND1 = { boardMeshes: 17, boardFinishes: 4, wordmarkVerts: 101, wordmarkXz: 97, wordmarkHash: 'a0831dd0197a' };

// ---- vertex level access (local to a layer node), needed to measure depth and fingerprints
function glbBin(buf) {
  const jlen = buf.readUInt32LE(12), off = 20 + jlen;
  assert.equal(buf.readUInt32LE(off + 4), 0x004e4942, 'second chunk is BIN');
  return buf.subarray(off + 8, off + 8 + buf.readUInt32LE(off));
}
function accessorVec3(gltf, bin, ai) {
  const a = gltf.accessors[ai], bv = gltf.bufferViews[a.bufferView];
  assert.equal(a.componentType, 5126, 'POSITION is float32');
  const off = (bv.byteOffset || 0) + (a.byteOffset || 0), stride = bv.byteStride || 12, out = [];
  for (let i = 0; i < a.count; i++) out.push([0, 1, 2].map((k) => bin.readFloatLE(off + i * stride + k * 4)));
  return out;
}
// Every mesh node under a layer node, with vertices in the layer's local frame
// (the layer node's own matrix is skipped, as in the S2 local bounds).
function layerMeshes(gltf, bin, layerIdx) {
  const out = [];
  const walk = (idx, parent) => {
    const n = gltf.nodes[idx], m = mul(parent, nodeMatrix(n));
    if (n.mesh != null) {
      for (const prim of gltf.meshes[n.mesh].primitives) {
        const verts = accessorVec3(gltf, bin, prim.attributes.POSITION).map((p) => [0, 1, 2].map((r) => m[r] * p[0] + m[4 + r] * p[1] + m[8 + r] * p[2] + m[12 + r]));
        const lo = [0, 1, 2].map((k) => Math.min(...verts.map((v) => v[k]))), hi = [0, 1, 2].map((k) => Math.max(...verts.map((v) => v[k])));
        out.push({ name: n.name || '', mat: prim.material != null ? gltf.materials[prim.material] : null, verts, lo, hi });
      }
    }
    for (const c of n.children || []) walk(c, m);
  };
  for (const c of gltf.nodes[layerIdx].children || []) walk(c, IDENT);
  return out;
}
const lum = (c) => 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2];
const base = (m) => m?.pbrMetallicRoughness?.baseColorFactor || [1, 1, 1, 1];
const metal = (m) => m?.pbrMetallicRoughness?.metallicFactor ?? 1;
const rough = (m) => m?.pbrMetallicRoughness?.roughnessFactor ?? 1;
const finishKey = (m) => JSON.stringify([base(m).map((v) => +v.toFixed(2)), +metal(m).toFixed(2), +rough(m).toFixed(2), !!m?.pbrMetallicRoughness?.baseColorTexture, !!m?.normalTexture, !!m?.pbrMetallicRoughness?.metallicRoughnessTexture]);
const isTealEmitter = (m) => m?.emissiveFactor && m.emissiveFactor[1] > m.emissiveFactor[0] + 0.1 && m.emissiveFactor[2] > m.emissiveFactor[0] + 0.1;
const imageNameOf = (gltf, texInfo) => (texInfo ? gltf.images?.[gltf.textures?.[texInfo.index]?.source]?.name || '' : '');
const sha12 = (s) => crypto.createHash('sha1').update(s).digest('hex').slice(0, 12);

async function round() {
  const { gltf, top, bytes } = await gltfOfAsset();
  const bin = glbBin(bytes);
  return { gltf, top, bytes, bin, board: layerMeshes(gltf, bin, top[2]), cover: layerMeshes(gltf, bin, top[0]) };
}

test('product-model S12/L2: the LED is a recessed optical element with measurable socket depth, teal, in its approved position and proportions', async () => {
  const { gltf, cover } = await round();
  const shell = cover.slice().sort((a, b) => (b.hi[0] - b.lo[0]) * (b.hi[2] - b.lo[2]) - (a.hi[0] - a.lo[0]) * (a.hi[2] - a.lo[2]))[0];
  const emit = cover.filter((p) => isTealEmitter(p.mat));
  assert.ok(emit.length >= 1, 'a teal emissive LED element exists on the cover');
  const lo = [0, 1, 2].map((k) => Math.min(...emit.map((p) => p.lo[k]))), hi = [0, 1, 2].map((k) => Math.max(...emit.map((p) => p.hi[k])));
  const cx = (lo[0] + hi[0]) / 2, cz = (lo[2] + hi[2]) / 2, w = hi[0] - lo[0], d = hi[2] - lo[2];
  // Round 1 approved: strip x -4.8..4.8, z 2.925..3.475 (centre 3.2, 9.6 by 0.55), brand teal.
  assert.ok(Math.abs(cx) <= 0.1 && Math.abs(cz - 3.2) <= 0.1, `emitter centre (${cx.toFixed(2)}, ${cz.toFixed(2)}) stays at (0, 3.2)`);
  assert.ok(Math.abs(w - 9.6) <= 0.2 && Math.abs(d - 0.55) <= 0.1, `emitter proportions ${w.toFixed(2)} x ${d.toFixed(2)} stay 9.6 x 0.55`);
  for (const p of emit) {
    const c = p.mat.pbrMetallicRoughness.baseColorFactor, e = p.mat.emissiveFactor;
    assert.ok(c[1] > c[0] + 0.3 && c[2] > c[0] + 0.3 && e[1] > 0.2 && e[2] > 0.2, 'the LED stays brand teal');
  }
  // Depth: the emitter sits below the surrounding top face. Surface height is read from
  // the shell vertices around the LED (the rim a socket is cut into).
  // Nearest top-face vertices to the LED centre (the rim of a cut socket, or the crowned
  // surface itself on a coarse shell); underside vertices are excluded.
  const topFace = shell.verts.filter((v) => v[1] > shell.lo[1] + 0.2);
  const around = topFace.map((v) => ({ v, d: Math.hypot(v[0] - cx, v[2] - 3.2) })).sort((a, b) => a.d - b.d).slice(0, 16).map((o) => o.v);
  assert.ok(around.length > 0, 'shell has top face vertices near the LED');

// ---- vertex level access (local to a layer node), needed to measure depth and fingerprints
function glbBin(buf) {
  const jlen = buf.readUInt32LE(12), off = 20 + jlen;
  assert.equal(buf.readUInt32LE(off + 4), 0x004e4942, 'second chunk is BIN');
  return buf.subarray(off + 8, off + 8 + buf.readUInt32LE(off));
}
function accessorVec3(gltf, bin, ai) {
  const a = gltf.accessors[ai], bv = gltf.bufferViews[a.bufferView];
  assert.equal(a.componentType, 5126, 'POSITION is float32');
  const off = (bv.byteOffset || 0) + (a.byteOffset || 0), stride = bv.byteStride || 12, out = [];
  for (let i = 0; i < a.count; i++) out.push([0, 1, 2].map((k) => bin.readFloatLE(off + i * stride + k * 4)));
  return out;
}
// Every mesh node under a layer node, with vertices in the layer's local frame
// (the layer node's own matrix is skipped, as in the S2 local bounds).
function layerMeshes(gltf, bin, layerIdx) {
  const out = [];
  const walk = (idx, parent) => {
    const n = gltf.nodes[idx], m = mul(parent, nodeMatrix(n));
    if (n.mesh != null) {
      for (const prim of gltf.meshes[n.mesh].primitives) {
        const verts = accessorVec3(gltf, bin, prim.attributes.POSITION).map((p) => [0, 1, 2].map((r) => m[r] * p[0] + m[4 + r] * p[1] + m[8 + r] * p[2] + m[12 + r]));
        const lo = [0, 1, 2].map((k) => Math.min(...verts.map((v) => v[k]))), hi = [0, 1, 2].map((k) => Math.max(...verts.map((v) => v[k])));
        out.push({ name: n.name || '', mat: prim.material != null ? gltf.materials[prim.material] : null, verts, lo, hi });
      }
    }
    for (const c of n.children || []) walk(c, m);
  };
  for (const c of gltf.nodes[layerIdx].children || []) walk(c, IDENT);
  return out;
}
const lum = (c) => 0.2126 * c[0] + 0.7152 * c[1] + 0.0722 * c[2];
const base = (m) => m?.pbrMetallicRoughness?.baseColorFactor || [1, 1, 1, 1];
const metal = (m) => m?.pbrMetallicRoughness?.metallicFactor ?? 1;
const rough = (m) => m?.pbrMetallicRoughness?.roughnessFactor ?? 1;
const finishKey = (m) => JSON.stringify([base(m).map((v) => +v.toFixed(2)), +metal(m).toFixed(2), +rough(m).toFixed(2), !!m?.pbrMetallicRoughness?.baseColorTexture, !!m?.normalTexture, !!m?.pbrMetallicRoughness?.metallicRoughnessTexture]);
const isTealEmitter = (m) => m?.emissiveFactor && m.emissiveFactor[1] > m.emissiveFactor[0] + 0.1 && m.emissiveFactor[2] > m.emissiveFactor[0] + 0.1;
const imageNameOf = (gltf, texInfo) => (texInfo ? gltf.images?.[gltf.textures?.[texInfo.index]?.source]?.name || '' : '');
const sha12 = (s) => crypto.createHash('sha1').update(s).digest('hex').slice(0, 12);

async function round() {

  const bin = glbBin(bytes);
  return { gltf, top, bytes, bin, board: layerMeshes(gltf, bin, top[2]), cover: layerMeshes(gltf, bin, top[0]) };
}
